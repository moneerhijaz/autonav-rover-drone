Autonomous Rover + Drone Project

Tank styled rover for control over rough surfaces, 2D IR for accurate mapping, (possible camera),
camera equipped drone for AI integration, and an Orin Nano to run everything, and a Teensy 4.1 for
quick controls. 

This duo is capable of mapping out rough areas and can be used to search for specific things. One
example is search and rescue, mapping out areas while looking for people in need.
  

Goal for this project:
    0. Set up base and connect to all necessary parts
    1. Create rover capable of manual control
    2. Rover capable of autonav using camera/lidar
    3. Connect drone capable of manual control
    4. Create an autonomous landing mechanism
    5. Make the drone capable of flying autonomously
    6. Stream drone data to rover to map out areas and search for things
    7. Stress test in real scenario to prove its effectiveness
