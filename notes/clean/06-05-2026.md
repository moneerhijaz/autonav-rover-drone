# ROS 2 Notes

**Date:** July 5, 2026

## ROS 2 Package Commands

### List all installed ROS 2 packages

```bash
ros2 pkg list
```

**Explanation**

Shows all ROS 2 packages available in the current environment.

* `ros2`: ROS 2 command-line tool
* `pkg`: package-related commands
* `list`: lists available packages

---

### List executables in a package

```bash
ros2 pkg executables <package_name>
```

**Explanation**

Shows the executables that belong to a specific ROS 2 package.

* `ros2`: ROS 2 command-line tool
* `pkg`: package-related commands
* `executables`: lists runnable executables
* `<package_name>`: name of the package to inspect

Example:

```bash
ros2 pkg executables turtlesim
```

**Explanation**

Lists executables inside the `turtlesim` package.

---

### List executables from all packages

```bash
ros2 pkg executables
```

**Explanation**

Shows executables from all available ROS 2 packages.

* `executables`: lists package executables
* Without `<package_name>`, ROS 2 checks all packages

---

## Running ROS 2 Executables

### Run an executable from a package

```bash
ros2 run <package_name> <executable_name>
```

**Explanation**

Runs a specific executable from a ROS 2 package.

* `ros2`: ROS 2 command-line tool
* `run`: runs an executable
* `<package_name>`: package that contains the executable
* `<executable_name>`: executable to run

Example:

```bash
ros2 run turtlesim turtlesim_node
```

**Explanation**

Runs the `turtlesim_node` executable from the `turtlesim` package.

## Launch Files

### Run a ROS 2 launch file

```bash
ros2 launch <package_name> <launch_file>
```

**Explanation**

Starts one or more ROS 2 nodes using a launch file.

* `ros2`: ROS 2 command-line tool
* `launch`: runs a launch file
* `<package_name>`: package containing the launch file
* `<launch_file>`: launch file to run

Example:

```bash
ros2 launch ldlidar_node ldlidar_with_mgr.launch.py
```

**Explanation**

Launches the LD19 LiDAR driver using the launch file from the `ldlidar_node` package.

* `ldlidar_node`: package containing the LiDAR driver
* `ldlidar_with_mgr.launch.py`: launch file used to start the LiDAR node and manager

# LD19 LiDAR with RViz2

## General Steps

1. Start an X server if using a GUI over SSH.
2. SSH into the robot or Linux machine.
3. Run the LiDAR driver.
4. Open RViz2.
5. Set the RViz2 fixed frame.
6. Add a `LaserScan` display.
7. Select the correct scan topic.

---

## SSH into the Linux machine

```bash
ssh <hostname_or_ip>
```

**Explanation**

Connects to another machine using SSH.

* `ssh`: starts a secure shell connection
* `<hostname_or_ip>`: hostname, SSH alias, or IP address of the machine

---

## Run the LD19 LiDAR driver

```bash
ros2 launch ldlidar_node ldlidar_with_mgr.launch.py
```

**Explanation**

Starts the LD19 LiDAR driver.

* `ros2`: ROS 2 command-line tool
* `launch`: runs a ROS 2 launch file
* `ldlidar_node`: package containing the LD19 LiDAR driver
* `ldlidar_with_mgr.launch.py`: launch file for starting the LiDAR node

---

## RViz2 Settings

```text
Fixed Frame: ldlidar_link
LaserScan Topic: /ldlidar_node/scan
```

**Explanation**

These settings allow RViz2 to display the LiDAR scan data correctly.

* `Fixed Frame`: the coordinate frame RViz2 uses as the reference frame
* `ldlidar_link`: frame published by the LiDAR driver
* `LaserScan Topic`: topic used by the RViz2 `LaserScan` display
* `/ldlidar_node/scan`: topic where the LiDAR scan data is published
